# F-audit: no-legacy generation compute audit (terminal Phase F slice)

## 0. Why

Phase F re-baselined generation onto a unified streaming core (FR0, `generation/_streamed.py`) with a route-independence contract (resident == streamed, byte-identical), a windowed_date column (FR1), and local 1M/10M capacity evidence (F4a). FR3 (Rust generation kernel selection) was SHELVED after it measured SLOWER than vectorized RNG, so generation computes every value on Python/numpy and NEVER on the Rust companion. F-audit is the mandatory terminal slice that PROVES, from a matrix DERIVED FROM THE DISPATCH PREDICATES (not observed dispositions), that each generator kind runs on its classified compute backend, that generation makes ZERO compiled-companion calls BY DESIGN (the predicate that keeps it so is a guarded invariant, not an accident), and that the production mixed route holds across the generate -> mask -> sink seam (the mask half cites D-audit; F-audit adds the generate side + the seam). Scope is the generation COMPUTE backend and its route/seam, not the sink orchestration or the retained legacy whole-table oracle. No new compute path is built; no production behavior changes; no hard-deletes are planned (deletion is opportunistic only, graphify-traced, and none is expected).

## 1. What exists

- **Two-level generation dispatch (the predicates the matrix derives from):**
  - **(A) Whole-plan semantic admission** `generation/_admission.py`: `ADMISSION_MATRIX` (:38-54) marks `sequence`, `categorical`, `faker`, `reference`, `windowed_date` eligible and `formula`, `statistical`, `derived`, `derived_aggregate`, `grouped_series`, `group_key` ineligible; `classify_plan` -> `classify` (:217-246) is the ladder (`determinism=="fresh"` declines; family-declined; per-kind type/eligibility checks; `faker_is_built_in` (:114-135) splits built-in vs custom). Whole-plan rule: `all(c.eligible ...)` (:74-76) — ONE ineligible column sends the WHOLE plan to legacy.
  - **Route into legacy vs core** `generation/_streamed.py` `run_generation`: `admission = classify_plan(...)` (:331); `if not admission.eligible: return _run_legacy(...)` (:337-348) — the single legacy branch, which calls `synthesize._generate_tables_from_config` and tags `reason=f"legacy:{admission.reason()}"` (`_run_legacy` :481-531).
  - **(B) Per-column kind dispatch** `generation/_column_streams.py` `make_column_stream` (:246-290): the `kind ==` ladder (sequence/categorical/faker/reference/windowed_date) wrapped by `NullMaskedStream` when `null_probability > 0` (:289-290). Faker pool-vs-live: `_faker_stream` (:293-328) consults `_faker_pool.pool_eligible` (:239-273; TABLE row_count vs `N_THRESHOLD=50_000`, closed type + locale allowlists), returning `PooledFakerStream` or falling back to `PerRowFakerStream`.

## 2. The change (derive the matrix, audit it, lock zero-companion, audit the seam, fence vacuity)

- **(A) DERIVE the generation compute-admission matrix from the predicates, then audit against it.** New data module `tests/parity/_f_audit_matrix.py` (mirrors `_d_audit_matrix.py`): independently of observed dispositions, enumerate per generator kind (from the `GenerateColumnConfig.type` Literal) x faker-pooled-vs-live x core-eligible-vs-legacy (from `_admission.ADMISSION_MATRIX` + the `classify` ladder) x companion-present-vs-absent, the EXPECTED compute classification, exactly one of:
  - **no_selection** (sequence — `_NO_EVENT_KINDS`);
  - **python_rng_selection** (categorical, reference — `random.Random(...).choices/choice`);
  - **numpy_selection** (pooled-faker, admitted when TABLE row_count >= `N_THRESHOLD` and type/locale allowed — `np.random.default_rng(...).integers`, pool_construction sub-path);
  - **live_provider_generation** (live/per-row faker — below threshold, opted-out, or custom/unresolved provider);
  - **formula_expression** (formula, referenced-formula, and derived rows that eval);
  - **legacy-whole-table** (formula / statistical / derived / derived_aggregate / grouped_series / group_key — these make the plan INELIGIBLE, so the whole plan routes to `_run_legacy`; classified by the admission predicate, not a per-column backend);
  - **admitted-but-unobserved** (windowed_date — eligible to the core yet outside the witness taxonomy, `_UNOBSERVED_KINDS`; audited by admission + populated-rows, not a selection label);
  - **sampler-only** (composite — never dispatched by `generate_tables`; an EXPLICIT exclusion, never a fabricated positive witness).
  Coverage guard: the audit fails if a Literal kind is unclassified (mirrors `test_phase_f_f0_matrix.py`). The matrix is the test's source of truth; the audit asserts each kind hit its CLASSIFIED backend.
- **(B) Consolidated no-legacy generation audit (the headline, none exists today).** New `tests/parity/test_phase_f_audit_no_legacy.py`: one cross-cutting sweep over the derived matrix that, for every CORE-eligible kind, asserts via the witness that the classified backend fired on NONEMPTY live positions (value-equality evidence), and for every LEGACY family asserts `classify_plan(...).eligible is False` with the expected `reason` AND that `run_generation` takes the `_run_legacy` branch (not a per-column fabrication). Each positive cell is paired with a discard-and-recompute mutant (reuse the `_f0_witness` mutant harness): discard the recorded backend's values and recompute the column independently -> the value-equality witness MUST fail.
- **(C) Lock zero-companion-by-design at the PREDICATE level (the no-legacy core claim).** Assert (a) over the full matrix, no generation column reports `compiled_index_selection`; AND (b) the predicate guard — a mutant that flips EITHER generation pool entry point to the deterministic sampler (`PooledSelector.select` / `_build_and_sample_returning_pool` -> `PoolSampler.sample(deterministic=True)` / `_derive_pool_indices`) makes `generate_tables` call the compiled index kernel, which a companion-call spy MUST catch (audit red). This proves the companion-free property is held by a guarded predicate, not by accident. (Extends, does not duplicate, the single `compiled-not-called` assertion in `test_phase_f_f0_witness.py`.)
- **(D) Audit the generate -> mask -> sink SEAM (production mixed route).** Extend the mixed-route witness (`test_phase_f_f2_mixed_backend_witness.py` / `_f2_backend_witness.py` / `_f2_mixed_support.py`) so the GENERATE half is audited alongside the existing mask-half kernel witness: in the `run_pipeline` mixed route (generated parent + masked child over one FK edge), assert the generated parent columns run on their classified Python/numpy backends with ZERO companion calls, the mask half runs on D-audit's kernels (CITE `test_phase_d_audit_no_legacy.py`, do not re-derive), and the hand-off is correct (generated parent -> masked child FK, observable in the orphan row count). Non-vacuity: a mutant that routes the generated parent through legacy, or makes a generation companion call, fails.
- **(E) Fence the empty/all-null vacuity hole (non-vacuity bar).** The positive backend witnesses in `_f0_witness._classify_one` can be satisfied vacuously by an all-null or zero-row column (empty `live_positions()`). The audit (and, if cleanest, a test-side guard in `_f0_witness.py` — test infra, NOT `src/`) requires a positive backend witness to have >= 1 live position; empty / all-null / zero-row columns are audited SEPARATELY (Arrow `null` type per the matrix all-null row; NO positive backend claim). Concrete mutant: an all-null column that would otherwise pass a positive backend assertion is REJECTED by the non-vacuity guard.

Document the generation compute families and by-design exceptions in the Phase-F close: Python/numpy-by-design families (sequence/categorical/reference/pooled-faker/live-faker/formula), legacy-whole-table families (formula/statistical/derived/derived_aggregate/grouped_series/group_key), windowed_date (admitted-but-unobserved), composite (sampler-only), formula wall-clock + statistical DP (deferred). ## 3. Risks (reproduce, do not smooth)

- **Vacuous audit.** The sweep must prove the classified backend held the COLUMN's values (not merely "a dispatch ran"). Reuse the `_f0_witness` value-equality + discard-recompute mutant harness; an all-null column must NOT satisfy a positive witness (part E). A legacy family must be proven to take `_run_legacy`, not just to be `eligible is False`.
- **Matrix drift from predicates.** The matrix is DERIVED from `_admission.ADMISSION_MATRIX` + the `classify` ladder + `pool_eligible`, NOT from `TODAY_BASELINE` / `EXPECTED_SELECTION`. If a kind's predicate and its row disagree, that is a finding, not a fixture to patch. The coverage guard fails if a Literal kind is unclassified.
- **Companion-mutant correctness.** The part-C mutant must make `generate_tables` ACTUALLY reach `_derive_pool_indices` -> compiled kernel (a real deterministic re-point), caught by a companion-call spy — not a weaker "label changed" check. If the companion is absent in the test env, the byte-identical Python reference still runs; the spy must assert the deterministic PATH was taken regardless of companion presence.
- **Seam scope.** The seam test audits the GENERATE side + hand-off; the mask side CITES D-audit (`test_phase_d_audit_no_legacy.py`), it does not re-derive it. `NEEDS_COMPANION` marks the mask-kernel leg; the generate-side + legacy-decline assertions must also run WITHOUT the companion.
- **Module size + physical-seam sentry.** New test files only; no `execution/` module changes expected. If part E edits `_f0_witness.py` (tests/, not execution/), no sentry entry is needed; confirm no `src/` change sneaks in.
- **Determinism envelope untouched.** No seed, no selection, no order changes.

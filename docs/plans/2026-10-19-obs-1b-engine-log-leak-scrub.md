# OBS-1b: engine log-leak scrub + safe error-summary + sentry blind-spot closure

## 0. Why

The error-message survey confirmed raw-value/exception leaks in the engine, including a BROAD user-facing one (any exception message reaches the job's visible `error` via the isolated-run envelope), and leak-sentry blind spots that let them through. OBS-1b scrubs the log sites to type-only, replaces the user-facing error field with a safe summary that still carries the markers the route governor needs, and extends the sentry so the class cannot silently reappear. No masking/generation behavior or accepted-job output changes.

## 1. What exists

- Leak sentry `tests/sentry/test_log_interpolation.py`: AST ratchet over `logger.*` calls only (`_logger_aliases`, `_LEVELS` :49), name-based `RISKY_NAMES` (:23-48; NO z3/z5), `ALLOWLIST` (:54-72) with four "Observability follow-up" entries (:68-71): `faker_setup._load_txt`/`_load_json`, `storm/profiler._run_storm_inner`, `transforms/base._log_stats`. The checker inspects EXPRESSIONS, not assignment provenance.

## 3. Risks

- Breaking route fallback (P1-3): the governor matches markers in `error`; a scrub that drops them silently stops legitimate rerouting. Mitigate: consumer audit + preserve the exact markers + governor regressions (eligible fallback trips; genuine crash classifies). This is the highest risk - treat the `error` field as a contract, not a log line.
- Missing a producer (P1-2): the leak is across tail + worker envelope + in-process; fixing only the final constructor leaves `exception_error_text`'s non-Arrow messages flowing. Cover all producers + test worker-envelope AND in-process with a NON-Arrow sentinel.
- Sentry false-negative (P1-1): name additions alone miss `stderr_tail`/`stdout_tail`; need named-sink + bounded assignment tracking, proven red on the real pre-fix expression.
- Lost debuggability (P2-4): do NOT claim "see server logs" unless a real safe correlated event exists; retain return code/signal/reason/memory evidence in the summary so a crash is still diagnosable without raw child output.
- Sentry false-positive from geo names: sweep; fix or justify-allowlist.
- Module caps + physical-seam sentry: test-side + error-string edits; census must not grow.

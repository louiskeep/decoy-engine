Non-deterministic categorical becomes **reproducible** (seeded), keyed by **global row position** (NOT by source value), so it stays "non-deterministic" in the privacy sense (no stable value->category mapping, not a pseudonymization join key) while gaining run-to-run reproducibility and chunk-safety, which lets it run on the native chunked fast path to 100M. No truly-random/unseeded opt-in for now (possible future add-on; do not build it now). This reverses the current deliberately-documented "two non-deterministic runs differ" contract (`_categorical.py:6-10`).

**Research-first (established in-repo methodology, reuse not reinvent):** this is exactly the shape `windowed_date` already uses via the durable-global-row-number (DGRN) machinery. C1b mirrors it; it introduces no new RNG/crypto primitive.

## 1. Goal and scope

Non-deterministic categorical today draws a whole-column vector from an **unseeded** `np.random.default_rng()` (`_categorical.py:214-231`): non-reproducible by design, and it fails the chunked preflight gate C1 added (`categorical_nondeterministic_not_chunk_safe`). C1b redefines its semantics to a **seeded, position-keyed** draw and admits the result to the native chunked route with byte parity against the (new) seeded pandas-oracle route.

New semantics (both the whole-frame/oracle path and the native chunked path must produce these IDENTICAL bytes): for each non-null row at global index `g = row_offset + local_index`, the category is a pure function of `(mask_key, namespace, g)` and the category set / CDF:
- Uniform: `idx = derive_index(mask_key, namespace, g.to_bytes(8, "big"), pool_size=len(categories))` -> `categories[idx]`.
- Weighted: `bucket = derive_index(mask_key, namespace, g.to_bytes(8, "big"), pool_size=_WEIGHTED_CDF_RES)` then the SAME CDF `bisect_right` / `searchsorted(side="right")` mapping the deterministic path already uses (`_categorical.py:196-213`, `_categorical_ext.py:112-120`, differential-pinned equal).
- Nulls preserved positionally (restored from the SOURCE column's null mask).

This keys on **row position**, not the source value, so it is non-deterministic (same value at different rows can differ; different values at the same row index get the same category) yet reproducible and chunk-safe.

In scope: seeded non-deterministic categorical that is otherwise native-admissible = has a namespace (the `derive` namespace), explicit all-string categories (no `from_profile`), buildable weights/CDF, string source column. Uniform and weighted.

Out of scope (each unchanged):
- Deterministic (value-keyed) categorical: C1, unchanged.
- Non-admissible categorical (numeric/non-string categories, non-string source, bad weights): stays on the oracle with existing behavior; must NOT be string-cast or position-keyed.
- `when:` predicates on a seeded non-det categorical: **rejected** (section 3, hazard 2), mirroring DGRN's `windowed_date`+`when` rejection. Position keying is parity-safe only when row order/count is identical across legs; `when:` filters rows, breaking that.
- FK-key columns: a position-keyed categorical must NOT be treated as FK-self-mask-safe (section 3, hazard 1), mirroring DGRN keeping position-keyed strategies disjoint from value-keyed `CHUNK_SAFE_STRATEGIES`.
- The truly-random/unseeded variant: removed (Option A). No unseeded path remains for categorical.

## 3. Semantics decision + the two hazards (both DGRN-precedented)

**Decision: seeded, position-keyed via the global row index, using the existing `derive_index` + shared CDF path, mirroring windowed_date.** The weighted path switches from numpy `p=` normalization to the deterministic branch's CDF/`bisect_right` mapping, so (a) oracle and native are byte-identical and (b) uniform/weighted reuse the one kernel. The output distribution is still the configured weighting (the CDF encodes the weights); only the DRAW source changes (unseeded numpy -> keyed derive over row index).

**Hazard 1 (FK-self-mask safety).** A position-keyed column is NOT value-keyed, so it must NOT be admitted as FK-self-mask-safe (a parent and child keyed by position would not agree). Mirror DGRN: keep seeded-non-det categorical OUT of the value-keyed `CHUNK_SAFE_STRATEGIES` / FK-self-mask-safe set; treat it like `CHUNK_DGRN_STRATEGIES` (position-admitted). The plan must identify the exact FK-safety set(s) and keep this variant out of them, with a test.

**Hazard 2 (`when:` predicates).** `run_with_when_gate` passes only matching rows, so the oracle enumerates the filtered subset `0..matches-1` while a chunk enumerates durable positions -> parity breaks. Reject seeded-non-det categorical + `when:` with a dedicated code, mirroring `reject_windowed_date_when`. (Deterministic/value-keyed categorical + `when:` is unaffected and stays as-is.)

**Row-offset domain:** reuse `validate_base_row_offset`/`validate_chunk_row_offset_range` (`chunked_row_offset_out_of_domain`); the 8-byte key domain is `0..2**64-1`.

## 4. Implementation

1. **Oracle strategy (`_categorical.py`), the shared semantics.** Replace the unseeded else-branch (`:214-231`) with the seeded position-keyed draw: for each non-null row at global index `g = ctx.row_offset + i`, compute the category via `derive_index(ctx.mask_key, plan.namespace, g.to_bytes(8,"big"), pool_size=...)` + (weighted) the shared CDF `bisect_right`. Require `plan.namespace` (raise `categorical_requires_namespace`, as the deterministic branch does). Nulls preserved positionally. Rewrite the module docstring `:6-10` to document the new reproducible position-keyed contract. This one change makes the whole-frame and oracle-chunked legs correct (oracle `row_offset` already threaded).
2. **Native plumbing (the one wire).** Add a `row_offset` parameter to `_mask_chunk_native` (`native/_chunk_masking.py:190`) and pass `row_offset` at the call site (`_chunked_entry.py:218`). In the seeded-non-det categorical branch, build the per-row global-index key column `[row_offset .. row_offset+n)` (as `pa` array of 8-byte keys, matching `g.to_bytes(8,"big")` canonicalization) and feed THAT to `native_categorical` as the keyed input; restore nulls from the SOURCE column. Add a `row_offset`/key-column path to `native_categorical` (`_categorical_ext.py:40`) OR a sibling entry that takes the key column; the kernel (`derive_index_batch`) is unchanged. Fix the null-mask invariant to compare against the SOURCE nulls, not the index column.
3. **Distinguish the two categorical modes on the native route.** The native categorical branch must select value-keyed (deterministic, C1) vs position-keyed (seeded non-det, C1b) from the column's config (`is_deterministic_categorical`). Deterministic keeps C1's exact path (source-value keyed). Non-det (now seeded) takes the row-index-keyed path. Both share the kernel + CDF.
4. **Lift the preflight gate for the seeded case.** Narrow `_chunked.py:322-324` / `is_nondeterministic` so a seeded non-det categorical that is otherwise admissible (namespace + explicit all-string categories + string source) is NOT appended to `nondeterministic_categoricals` and does NOT hit `reject_nondeterministic`. A non-admissible non-det categorical still rejects (keep the code for that residual case, or retire it if no residual case remains; the plan must state which and test it). `conditional_failures` (`_chunked_categorical.py:42-59`) already requires namespace + explicit categories; keep that for the non-det case.
5. **Hazard gates (section 3).** Add the `when:` rejection for seeded-non-det categorical (new code, mirror `reject_windowed_date_when`). Keep the variant out of the FK-self-mask-safe set; add it to the position-admitted treatment (`CHUNK_DGRN_STRATEGIES`-style) so FK safety is correct.
6. **Admission / source-type.** Reuse C1's string-source admission (`categorical_source_type_rejection`); a non-string source reroutes to the oracle before masking. Namespace required.
7. **Evidence/backend.** Seeded non-det categorical that runs natively reports `rust_companion` + `compiled_kernel_executed is True` (the kernel runs on any non-empty chunk; unlike bucket_perturb, categorical derives for every non-null row, so there is no all-unparseable degenerate class, but an empty/all-null chunk still runs no kernel -> `arrow_python`, honest per the C2 pattern). `kernel_calls["categorical"]` counts branch executions. Reuse C2's honest-evidence merge across both aggregation paths.
8. **Docs:** CHANGELOG + compatibility-contract (the determinism-contract change: non-det categorical is now reproducible/position-keyed; ROUTE behavior). Barry pass with exact-HEAD receipt. Update the roadmap + RECENTLY-SHIPPED on merge.
9. **Stale comments/docstrings:** the `_categorical.py` module docstring; any comment calling non-det categorical "unseeded"/"two runs differ"; the C1 gate docstrings in `_chunked_categorical.py` / `_chunked.py` that describe non-det as not-chunk-safe.

## 5. Acceptance tests (written before implementation; red-before recorded)

Parity contract: native chunked == oracle chunked == oracle whole-frame, byte-for-byte on values + Arrow type + metadata, order, warnings, errors, evidence. Mirror C1's `_chunked_categorical_support.py` / parity + admission suites.

1. **Position-keyed reproducibility + parity matrix.** Seeded non-det categorical (uniform + weighted), string source, over chunk shapes {empty, all-null, single-row, ragged, all-null-beside-valued, null-block-then-valued}, sizes {1, 7, 50_000}, threads {1, 4}. Assert native chunked == oracle chunked == oracle whole-frame per chunk and reassembled (values + type + metadata). THIS is the core proof that `row_offset` keying reproduces whole-frame bytes under any chunking.
2. **It is position-keyed, NOT value-keyed (the semantic pin).** (a) The same source value at two different row positions can map to different categories. (b) Two DIFFERENT source values at the same global row index map to the SAME category (proves keying is on position, not value). (c) Same seed + same row order -> identical output across runs (reproducible); different `mask_key` or `namespace` -> different output.
3. **Distribution.** Over a large column the category frequencies match the configured weights within tolerance (weighted) / uniform (unweighted) -- the existing skew/validity tests, retargeted to the seeded path.
4. **Determinism-mode separation.** A deterministic (value-keyed) categorical in the same config still uses the C1 value-keyed path (unchanged bytes); a non-det one uses the position-keyed path. Both in one table.
5. **Hazard 1 (FK).** A seeded non-det categorical on an FK key is NOT admitted as FK-self-mask-safe; assert it is handled by the position-admitted path, not the value-keyed FK-safe path, with the exact code.
6. **Hazard 2 (when).** Seeded non-det categorical + `when:` -> rejected with the new exact code (parity would otherwise break). Deterministic categorical + `when:` still works.
7. **Lifted preflight gate.** An admissible seeded non-det categorical no longer raises `categorical_nondeterministic_not_chunk_safe`; its table runs native (not vetoed). A non-admissible non-det categorical (no namespace / non-string categories) still fails with its exact code.
8. **Row-offset domain.** `base_row_offset` near `2**64` validated (`chunked_row_offset_out_of_domain`); a multi-chunk run advances the offset correctly so chunk 2's rows key off their true global indices (assert chunk-boundary rows match whole-frame).
9. **Evidence honesty (C2 pattern, applied up front).** Native run: `rust_companion` + `compiled_kernel_executed is True` + `kernel_calls["categorical"]` == bucket columns * emitted chunks; an empty/all-null-only admitted column reports `arrow_python` + flag False. Companion-absent downgrade -> `index_extension_unavailable` -> oracle, byte-identical, planned `rust_companion` + executed `pandas_oracle`.
10. **Forced-oracle proof (C2 lesson, applied up front).** EVERY forced-oracle leg in the new/updated suites captures route evidence and asserts `native_admitted is False` PLUS the exact column-qualified still-vetoed reason, so no test can silently become native-vs-native. Any oracle-forcing fixture uses a strategy that stays vetoed.
11. **Old-contract tests updated.** Inventory every test asserting the OLD unseeded "two runs differ" behavior; update to the new reproducible contract. No test weakened/skipped/xfailed to pass.

Record red-before (fails on current main: non-det categorical is vetoed + unseeded), green-after.

## 1. Goal and scope

Lift the chunked-route veto for seeded non-deterministic categorical, admit it to the chunked NATIVE route via a route-aware predicate, and execute it natively per chunk keyed by the per-chunk `uint64` global row offset, with byte-and-type parity: native chunked == oracle chunked == whole-frame.

Admissible (chunked native, seeded non-det categorical): non-deterministic AND namespace AND explicit all-string categories (no `from_profile`) AND buildable CDF (all config-known, checked at/before the config veto) AND a STRING source (checked post-first-chunk; non-string FAILS CLOSED) AND no `when:` AND not FK-affected.

In scope: lift the config veto for the config-admissible seeded case; a shared chunked-only positional admission predicate consumed in the route decision + evidence + prepared set; the native positional per-chunk execution (uint64 global-index column -> `derive_index_batch`, nulls from source); post-first-chunk non-string fail-closed; chunked output-type pin for the seeded variant; `when:` rejection on the chunked route; honest evidence (empty vs all-null distinguished); route-aware (full-frame physical stays closed).

OUT of scope (deferred, vetoes stay): multi-table split (C1b-iii); out-of-core (C1b-iv); full-frame physical native non-det (stays closed, B3); a NEW FK gate (not needed, MEDIUM 5). FK-affected seeded categorical stays off the native route via the EXISTING native FK reroute and runs chunked-oracle, reproducibly.

## 4. Implementation

1. **Shared chunked-only positional admission predicate (BLOCKER 1).** Define one predicate `is_chunked_positional_categorical(col_entry/first_chunk_schema)` = non-deterministic + namespace + explicit all-string categories + no from_profile + buildable CDF (+ string source once the first chunk is known). Consume it in exactly three chunked-only places: (a) `_dispatch._static_route_decision` as an explicit exception that admits the node to native despite the shared non-native fallback policy; (b) `plan_column_backends` so planned + executed evidence reports `rust_companion`; (c) `prepare_chunked_categoricals` so preparation uses the identical domain. Add a disagreement test proving the three return the same verdict. Do NOT touch `prepare_categorical`, `_requirements.py`, `native_route_eligibility`, `_shadow_bindings`, `_shadow_operators` (full-frame physical stays closed, B3).

Keep `conditional_failures`. Update `_chunked_categorical.py` prose to reflect "admissible seeded -> allowed; non-admissible -> rejected".
3. **Non-string source fails closed post-first-chunk (BLOCKER 2).** Once the first chunk is available, if a positional candidate's source is not string, FAIL CLOSED with the retained categorical chunked code (do NOT downgrade to the chunked oracle). 4. **Thread row_offset into the masker.** Add a `row_offset` param to `_mask_chunk_native` (`_chunk_masking.py:190-204`); pass the loop's per-chunk `row_offset` at `_chunked_entry.py:218-231`.
5. **Positional native execution (open Q1).** Add `native_categorical_positional(source, key_array, categories, cdf, mask_key, namespace, index_kernel, native_threads)` sharing a private gather/CDF helper with `native_categorical` (keep C1's signature + its input-null-mask invariant untouched). In `_mask_chunk_native`'s categorical branch, dispatch to the positional sibling when the prepared entry is the seeded positional variant; else C1's path.
6. **Chunked output-type pin + prepared set.** Add a chunked-only branch to `prepare_chunked_categoricals` (`native/_categorical_prepared.py:77-98`) that prepares the seeded variant (resolved categories + CDF) WITHOUT reusing `prepare_categorical`'s deterministic filter; mark it positional. 7. **`when:` rejection on the chunked route.** Add a `reject_*_when`-style gate for a seeded non-det categorical carrying `when:` (new code, mirror `reject_windowed_date_when`), invoked near `_chunked.py:300`. No new FK gate (MEDIUM 5); rely on the existing native FK reroute.
8. **Evidence (HIGH 4, honest).** Zero-row chunk: skip the compiled call, emit typed empty `string`, add to `kernel_idle`, do NOT set `compiled_kernel_executed`/increment for a run that did not happen. All-null non-empty chunk: run `derive_index_batch` and report compiled execution honestly. Mirror C2's empty-handling discipline.

## 7. Resolved design decisions (Codex round-1 answers folded)

1. **Positional native API:** a `native_categorical_positional` sibling sharing a private gather/CDF helper with `native_categorical`; pass source + a dense `pa.uint64()` key array separately; restore validity from source. Keeps C1's signature + null-mask invariant.
2. **Chunked prepared branch:** feasible and no other production consumer assumes deterministic-only beyond `_chunked_entry`, BUT insufficient alone -- the route-decision (`_dispatch`) and evidence (`plan_column_backends`) layers need the SAME positional predicate (BLOCKER 1).
3. **FK:** no new FK rejection needed; a declared relationship already forces the native route to oracle (`_dispatch.py:214`), and FK self-mask is hash-only. FK-affected seeded categorical runs chunked-oracle reproducibly. Do NOT claim a synthetic FK handler frame.
4. **Output pin:** yes; once the seeded variant is in `categorical_columns`, the rule (built before the fork, passed to both legs) pins both.

## 3. Semantics decision (round-1 confirmed correct)

Seeded, position-keyed via the global row index using `derive_index` + the shared integer CDF (round 1: `bisect_right` == native `searchsorted(side="right")`; distribution CDF-quantized to 1,000,000). The chunk-stability hazard (where match-ordinal != physical position across chunks) is a C1b-ii concern: C1b-ii rejects `when:`/FK non-det categorical on the chunked route, exactly as windowed_date does.

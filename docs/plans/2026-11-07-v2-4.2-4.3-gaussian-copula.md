## 1. FRAME

**Problem.** The engine's `statistical` generation (`generation/statistical/`) samples each column
on its own from `distribution-snapshot/v1`. Columns come out with the right shape but rows are
nonsense: every correlation between columns is lost. V2-4 adds a Gaussian copula, which keeps
pairwise dependence while reusing the per-column marginals the engine already fits.

**Definition of done.**

1. `fit_gaussian_copula(frame, *, seed, numeric_bins=10)` returns a frozen `GaussianCopulaModel`
   for a table of numeric and categorical columns, with nulls in any column.
2. `sample_gaussian_copula(model, n, *, seed, start=0)` returns a `pandas.DataFrame` of `n`
   synthetic rows. Row `start + i` is a pure function of `(model, seed, start + i)`, so a window
   equals the same rows of a full draw.
3. `model.to_dict()` / `GaussianCopulaModel.from_dict(d)` round-trip through JSON
   (`json.dumps(..., allow_nan=False)`), schema `decoy-gaussian-copula/v1`. `from_dict` is strict
   and never repairs.
4. The model stores no raw value beyond what `compute_distribution_snapshot` stores for the same
   frame and bin count (section 4.3 states the exact contents), plus the correlation matrix.
5. `pairwise_fidelity(real, synthetic)` scores every column pair with SDMetrics' definitions
   (correlation similarity, contingency similarity) and returns a frozen, value-free report.
6. Acceptance (section 9) shows correlation fidelity within tolerance, category frequencies and
   null rates within tolerance, determinism across processes, windowed equality, and a fail-before
   proof: an independent sampler with the same marginals fails the correlation assertions.

**Non-goals.**

- No wiring: no `strategy: copula`, no config key, no `decoy fit` change, no pinned-generation or
  native draw-site entry (the native determinism protocol's draw-site catalogue gets an entry when
  a later slice wires this in).
- No change to `distribution-snapshot/v1` or to `quality/` (V2-4.1 decides the artifact; DPS
  owns the DP fit).
- Not differentially private. V2-4.5 adds noise to the correlation release. The model is a
  sensitive artifact of the same class as the exact snapshot (section 4.3).
- No datetime or freetext columns: `fit` refuses them. Datetime needs a finer marginal than the
  snapshot's year bins; it is a follow-up.
- No conditional sampling, no constraints, no multi-table (V2-9).
- No new dependency, no scipy, no new reason code, no new exception class.
- Not a quality-report change: V2-4.4 puts the pairwise measure into the report.

**Risk: R2.** New privacy-relevant artifact (a fitted model carrying the snapshot's real category
labels and bin edges), a new statistical primitive, and a new persisted format with a versioned
reader. Nothing is persisted or run by the engine itself (dark), so rollback is reverting the
branch. Approver: independent plan and code review (Dennis), then the owner; owner instruction
2026-11-07 is not to merge.

## 2. Established solutions

Searches run (2026-11-07, WebSearch plus source reads): "SDV GaussianCopula categorical

from the RDT and SDMetrics source on GitHub (method only; `docs.sdv.dev` is not reachable from
this session); CPython's `statistics.py` (AS241 coefficients); R's `nmath/pnorm.c` (Cody).
In-codebase: `quality/snapshot.py`, `generation/statistical/`, `generation/pool`, `composite`,
`generation/window.py`, the native determinism protocol.

Findings and the source each part follows:

| Part | Source followed | Notes |
|---|---|---|
| Overall model | Gaussian copula (Nelsen, *An Introduction to Copulas*, 2nd ed., 2006, Sklar's theorem, sec. 2.3; Gaussian copula sec. 2.9) as used by SDV's GaussianCopula (Patki, Wedge, Veeramachaneni, "The Synthetic Data Vault", IEEE DSAA 2016) | method only: SDV, RDT and SDMetrics are under the Business Source License; `tests/sentry/test_sdv_import_sentry.py` already forbids importing them |
| Correlation estimate | semiparametric rank estimator: pseudo-observations `rank/(n+1)` mapped through `Phi^-1`, Pearson correlation of the normal scores (Genest, Ghoudi, Rivest, Biometrika 1995; the van der Waerden normal-scores rank correlation, efficient for the Gaussian copula per Klaassen and Wellner, Bernoulli 1997; Hoff, AOAS 2007, sec. 2) | ranks are computed at fit time and never stored |
| Marginal (numeric) | the snapshot's equal-width histogram, inverse CDF with uniform-within-bin (Devroye 1986, ch. II.2), as `statistical` already samples | SDV fits a parametric family (default beta) instead; we keep the snapshot representation so the model adds no new statistic of real values |
| Categorical encoding | RDT `UniformEncoder` (SDV's frequency-interval encoding): each category gets a sub-interval of [0, 1) of width equal to its frequency; fit places a value uniformly at random inside its interval; sampling maps a uniform back to the interval containing it; null is "just another category" (`missing_value_encoding='new_category'`) | RDT orders intervals by first appearance; we order by `(-count, label)` (the snapshot's own order) so the model does not depend on row order |
| Nulls in numeric columns | RDT `NullTransformer(missing_value_generation='from_column')`: a separate binary null-indicator variable that enters the copula | RDT fills the value column's nulls with the mean, which biases correlations toward zero; we instead estimate each value pair on pairwise-complete rows and repair the matrix (the use case Higham 2002 was written for) |
| Matrix repair | Higham, "Computing the nearest correlation matrix: a problem from finance", IMA J. Numer. Anal. 22 (2002): alternating projections with Dykstra's correction, unweighted (W = I); followed by an eigenvalue floor and diagonal rescaling (as statsmodels `corr_clipped`) so the result is strictly positive definite | SDV clips eigenvalues only; Higham gives the nearest matrix in Frobenius norm |
| `Phi` | W. J. Cody, "Rational Chebyshev approximations for the error function", Math. Comp. 23 (1969), as ACM TOMS Algorithm 715 `ANORM` (Cody 1993), the algorithm of R's `pnorm` | about 18 significant digits in exact arithmetic; three regions, vectorizes with `numpy.where` masks |
| `Phi^-1` | Wichura, Algorithm AS 241 `PPND16`, Appl. Statist. 37 (1988), the algorithm of R's `qnorm` and of CPython's `NormalDist.inv_cdf` | about 16 digits; coefficients taken from CPython's `statistics.py` |
| Sampling RNG | NumPy `PCG64` (O'Neill 2014) with `SeedSequence`; NEP-19 bit-stream stability; `advance()` for a seekable stream (the counter-based pattern `generation/window.py` cites, Salmon et al. SC 2011) | raw 64-bit outputs are converted to doubles by our own rule, so the stream does not depend on `Generator` method internals |
| Fidelity measure | SDMetrics `CorrelationSimilarity` (score `1 - |r_real - r_synth| / 2`, pairwise-complete rows, Pearson default, Spearman available) and `ContingencySimilarity` (score `1 - TVD` of the normalized joint frequency tables, nulls as their own category, continuous columns discretized into 10 bins) | method only |

Why custom code is needed: no allowed dependency provides a copula, a vectorized normal CDF or
inverse, or a nearest-correlation-matrix routine (scipy and statsmodels are not dependencies;
SDV is BSL). Each piece is a short, published algorithm and the tests pin it against an oracle
(`statistics.NormalDist`, `math.erfc`, Higham's published example).

## 4. Design notes

### 4.1 Fit (`_fit.py`)

1. Validate arguments (section 3). Call `compute_distribution_snapshot(frame, numeric_bins=b)`
   (default `categorical_top_k`). Refuse datetime and freetext. Build each column's marginal from
   its snapshot entry only (`_marginals.from_snapshot_entry`).
2. Latent scores, at fit time only, never stored:
   - numeric value variable: on non-null rows, average-tie ranks over `n_obs + 1`, mapped through
     `Phi^-1`; `NaN` on null rows;
   - numeric null-indicator (only when the column has both nulls and values): states `present`
     and `null` as frequency intervals (section 4.2), a uniform point inside the row's interval;
   - categorical: the row's state interval (a top label, `null`, or the collapsed tail `other`),
     a uniform point inside it.
   Uniform points use a `PCG64` stream from `seed` with the label `fit` (section 4.4).
3. Correlation: Pearson correlation of each pair of latent variables on rows where both are
   present (pairwise-complete). A pair with fewer than 3 shared rows, or zero variance on either
   side, gets 0. A value variable and its own null indicator get 0 (the indicator is constant
   where the value is present).
4. Repair with `nearest_correlation` (section 4.5), round to 12 decimals (the snapshot's
   `_FLOAT_PRECISION`, for the same determinism reason), and check the result factors.

### 4.2 Marginals (`_marginals.py`)

- Numeric: `bin_edges`, `bin_counts` from the snapshot. Inverse transform of `u` in (0, 1):
  `t = u * total`, bin `k` = first bin with cumulative count `> t`, value
  `edges[k] + (t - cum[k-1]) / counts[k] * (edges[k+1] - edges[k])`. Zero-count bins are never
  selected. A constant column (`edges = [c, c]`) returns `c`.
- Frequency intervals (categorical states and the numeric null indicator): states are the
  snapshot's `top_values`, plus `null` when `null_count > 0`, ordered by `(-count, kind, label)`
  so the order is a function of the counts and labels only; the collapsed tail `other`
  (`other_count > 0`) is always last. At sampling, `u` is scaled by `1 - p_other` before the
  interval lookup, so `other` mass is redistributed over the kept states in proportion (the
  `statistical` default `other_mode: redistribute`) and the mapping stays monotone. `other` is
  never emitted; no label outside the snapshot's `top_values` can be produced.
- Integer dtype test mirrors `statistical/_sample._is_integer_dtype` (a one-line predicate
  copied rather than imported from a private module, catalog item 6).

### 4.3 What the model stores (`_model.py`)

`to_dict()` has exactly these keys:

- `schema_version`: `"decoy-gaussian-copula/v1"`.
- `row_count`, `numeric_bins`.
- `columns`: list in frame order; each entry has `name`, `kind` (`numeric` | `categorical` |
  `empty`), `dtype`, `null_count`, `non_null_count`, and then either `bin_edges` and `bin_counts`
  (numeric) or `top_values` (`[{value, count}]`) and `other_count` (categorical). Every one of
  these is the identical field of the snapshot entry for that column.
- `correlation`: the strictly lower triangle of the repaired latent correlation matrix, row-major,
  floats rounded to 12 decimals. The latent variable order is derived from `columns` (not stored).

So the model contains the snapshot's real values (bin edges, whose ends are the column min and
max, and up to 20 real category labels per column) and nothing the snapshot does not hold: no
quantiles, mean, standard deviation, ranks, normal scores, row values or tail labels. The
correlation matrix is the only new statistic. It is a sensitive artifact in the same class as the
exact snapshot (`quality/snapshot.py` module docstring); a later wiring slice must put it behind
the same `allow_real_categories` consent as `statistical`. `__repr__` is value-free (column names,
kinds and the latent dimension only), so an accidental log line does not print labels.

`from_dict` validates everything listed in section 3 with strict types (catalog items 2 and 4):
`int` fields refuse `bool`, float fields accept `int` or `float` but refuse `bool` and strings, enum
fields are checked tokens, unknown and missing keys are refused (v1 has no minor versions; a v2
reader is a new schema). Consistency is checked, not trusted: bin counts sum to `non_null_count`,
category counts plus `other_count` sum to `non_null_count`, `null_count + non_null_count ==
row_count`, the correlation length matches the derived latent dimension, and the matrix factors
(Cholesky). A model built by `fit` and one read by `from_dict` go through the same constructor
validation, so there is one validator.

### 4.4 Sampling (`_sample.py`) and the RNG

- Seeds: `seed` is caller-supplied `bytes` (at least 16), never global state. The stream is
  `PCG64(SeedSequence(int.from_bytes(sha256(label || len(seed) || seed))))` with a distinct
  label for `fit` and `sample`, so passing the same bytes to both does not reuse a stream.
- Each row consumes exactly `d` raw 64-bit outputs (d = latent dimension), converted to doubles
  in (0, 1) as `((x >> 11) + 0.5) * 2**-53`. A window at `start` calls `advance(start * d)`, so
  row `i` depends only on `(model, seed, i)`.
- `W = Phi^-1(U)`; `Z = W L^T` with `L` the Cholesky factor of the stored matrix; `U' = Phi(Z)`;
  each column's marginal inverts its slice of `U'`. The product is accumulated column by column
  with elementwise numpy operations (no BLAS reduction), so a row's value does not depend on the
  batch size or on BLAS threading. Numeric null indicator: the row is null when its uniform falls
  in the `null` interval.
- Bit-identity holds for the same numpy build on the same CPU feature set; across machines it is
  not promised (section 10).

### 4.5 Nearest correlation matrix (`_nearest_corr.py`)

Higham 2002, Algorithm 3.3 with W = I: `Y0 = A`, `dS0 = 0`; repeat `R = Y - dS`,
`X = P_S(R)` (eigenvalues clipped at 0), `dS = X - R`, `Y = P_U(X)` (unit diagonal) until the
relative change is below `1e-12` or 500 iterations. Then floor eigenvalues at `1e-8`, rebuild and
rescale to unit diagonal (`D^-1/2 X D^-1/2`, which keeps it positive definite). An input that is
already a valid correlation matrix with minimum eigenvalue at least `1e-8` comes back within
`1e-12`.

### 4.6 Principles and structure

- Single responsibility per module: `_normal` (special functions), `_nearest_corr` (linear
  algebra), `_marginals` (one column's forward and inverse transform), `_model` (the artifact and
  its one validator), `_fit`, `_sample`, `_fidelity`. Each changes for one reason.
- Deep module: callers see four functions and one model type; latent layout, intervals and RNG
  framing are hidden.
- One place per fact: kind rules, bins and top-K live in the snapshot; the latent layout is
  derived from `columns` in one function used by fit, sample and `from_dict`; the schema version
  is one constant.
- No registry or descriptor: there are two column kinds with no expected stream of new ones
  inside this package (datetime would be the third); a `match` on kind in `_marginals` is enough.
- House style: typed frozen dataclasses for the model and report, no flag arguments.
- Logging: none. This is a pure library function with no job, like `compute_distribution_snapshot`;
  the wiring slice adds job events. Errors are value-free.

## 6. Pairwise fidelity measure (`_fidelity.py`)

For every unordered pair of columns present in both frames:

- numeric with numeric: `pearson = 1 - |r_real - r_synth| / 2` and `spearman` the same with
  Spearman's rho, each on that frame's pairwise-complete rows (SDMetrics `CorrelationSimilarity`;
  both are reported because a rank copula preserves Spearman by construction while Pearson also
  depends on the histogram marginal). A pair constant on either side scores `None` and is left out
  of the means.
- any pair with a categorical column: `1 - TVD` between the normalized joint frequency tables,
  null as its own category, numeric columns discretized into `bins` equal-width bins over the real
  column's range (synthetic values clipped into it) (SDMetrics `ContingencySimilarity`).

Kind comes from the dtype: numeric non-bool dtypes are numeric, everything else categorical. The
report holds `(column_a, column_b, metric, score)` tuples and per-metric means. It holds no values.

## 8. Fail-before proof

The correlation assertions in A3 and A4 are run against an independent sampler with the same
marginals: the copula's own output with each column permuted by a separate seeded permutation.
That is exactly what today's `statistical` generation produces in distribution (independent
columns with snapshot marginals). The prototype below shows it failing: Spearman similarity for
the strongest pair falls from 0.996 to 0.601.

Prototype evidence (scratch numpy prototype with `statistics.NormalDist`, n = 5,000 fit and
sample; fixture: `x = exp(z0)`, `y = z1^3 + z1`, `w = round(50 + 10 z2)` with 14% nulls that
depend on `z2`, categorical `c` (3 states from `z3`, 5% nulls), binary `f` from `z0`, binary `g`
from `z3`; latent correlations 0.8, -0.5, 0.6, -0.4, 0.5):

| Pair | Copula | Independent |

## 10. Known limits

- **Marginal resolution is the snapshot's.** Ten equal-width bins with uniform-within-bin sampling
  flatten skewed columns (a log-normal column puts most of its mass in one bin). This is the same
  marginal `statistical` produces; `numeric_bins` can raise it. Pearson similarity is lower than
  Spearman for such columns for this reason.
- **Categorical dependence is captured only as far as it is monotone in the frequency order.** A
  category whose relationship to a numeric column is not monotone in that order is attenuated
  (prototype: a 3-state column scored 0.972 against 0.944 independent). SDV's GaussianCopula has the
  same limit; a better model (for example one-hot latent variables) is a follow-up.
- **Missingness dependence is attenuated** by the uniform placement inside the indicator interval
  (prototype: real P(null | high x) 0.076, synthetic 0.120, independent 0.139).
- **Bit-identity is per platform.** The sampler uses numpy elementwise `exp`, `log`, `sqrt` and
  LAPACK Cholesky; results are identical across processes on one machine and numpy build but may
  differ in the last bits across CPU feature sets or numpy versions. `statistical` avoids this by
  sampling in pure Python; the wiring slice decides whether pinned generation needs that.
- **Dimension.** Fit is `O(n d^2)` and the repair `O(d^3)` per iteration with up to 500
  iterations; there is no cap on `d` here. Sampling memory is `n x d` floats per call, so a large
  `n` should be drawn in windows (`start`).
- **Bool columns come back as `"True"`/`"False"` labels**, as `statistical` returns them.

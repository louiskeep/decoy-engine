# INIT-WIZARD E0: a public strategy catalog in the engine

Date: 2026-11-07. Branch: `feat/iw-e0`, on engine main `b4c6915d`. Plan: INIT-WIZARD
(CLI `plan/init-wizard`, `docs/plans/2026-11-07-init-wizard.md`), slice E0, gate G-CATALOG,
AT-E0a and AT-E0b.

## Problem

The CLI wizard needs to know, for each masking strategy, whether it needs a namespace, whether it
is safe on a join key, which options an operator may set and where they go in the column entry.
That knowledge lived only in handler code and in hand-kept copies (`_KEY_STRATEGIES`, the CLI's
own lists), so a front end had to keep a parallel table that could drift.

## Change

- `StrategyOption` and `StrategyInfo` (frozen dataclasses in `execution/_adapter.py`) and
  `strategy_catalog()` in `execution/_strategies/__init__.py`, exported from `decoy_engine`.
  Every scalar handler declares `namespace_required`, `join_safe`, `wizard_options` and
  `offer_in_wizard` on its own class; the catalog reads `vars(type(handler))`, so an inherited
  default does not count and a handler without the four attributes fails at import.
- 16 strategies are offered in the wizard. `hash` is join-safe and offers no options, because
  `truncate` shortens the output and so breaks injectivity on a key.
- `_KEY_STRATEGIES` is derived from the `join_safe` rows (`fpe`, `hash`) instead of a literal set.
- Where a transform module has a public constant (`VALID_BUCKETS`, `SHIPPED_CODE_SETS`,
  `SUPPORTED_TYPES`, `CASCADE_LEVELS`), the option choices read it instead of a copy. The
  `text_mask` policy choices are a deliberate wizard subset, `code_set.mode` is the literal
  `("mask", "gen")`, and `bucketize` and `truncate` use handler-local constants.
- `example` values on each option are test data chosen to differ from the handler default; they
  are never a prompt prefill.
- Line-sensitive pins moved with the handlers: the draw-site `call_site` pins, nine catalogue
  digests in `tests/native/test_draw_sites_catalogue_pinned.py` (line numbers only, recomputed
  from both trees), `docs/native/draw-site-inventory.md` and `secret_material_census.json`.
- `tests/sentry/test_physical_seam_disconnection.py`: five handler files that gained only the
  catalog declarations join the byte-identity allowlist (`_derived_aggregate`, `_formula`,
  `_grouped_series`, `_passthrough`, `_redact`). None imports `execution.physical`, and the
  sentry's import sweep still checks that. This is the standing allowlist step for any slice
  that edits `execution/`, not a waiver.
- Tests in `tests/unit/strategy_catalog/test_catalog.py`: per-handler declarations, an
  independent expected option table, an entry run per offered strategy, wrong-level refusals,
  behavioral probes per option, join-safety checks on 1,000 distinct values and determinism
  checks.

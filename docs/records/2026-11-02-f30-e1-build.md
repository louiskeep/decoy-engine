Test shape notes:
- E-T1, E-T2, E-T7: a real `run_pipeline` (full frame) runs with the recorder bound through
  `use_progress`, then its output is published through `ParquetTransactionalSink` inside the same
  binding. A full-frame run does not write to a `sink=` (only the chunked lane streams into one, and that
  lane emits no `mask` phase), so the publish phase comes from the real sink's `publish_stored`.
- E-T2 carries `MARKER` in the table name, the column name, the source name (file and source key), every
  cell, and a `ValueError(MARKER)` raised in a `mask` phase. Non-vacuity: a parallel `CallbackSink` sees
  `MARKER` in `PhaseEvent.table`.
- E-T3: `PhaseEvent.__post_init__` already applies `safe_error_class`, so the recorder never sees the
  exception object. The recorder re-applies `safe_error_class` to `event.error_class`. The test covers
  both the real path (`channel.phase` raising `Leak_<MARKER>`) and an event altered after construction
  with `object.__setattr__`.
- E-T5: 200 repeats, each run with `max_spans=256` (two records, each with its own duration, none lost,
  none unmatched) and with `max_spans=1` (exactly one record, `dropped == 1`). The test replaces
  `_recorder._ns` with a version that sleeps 0.5 ms; the recorder calls it inside its locked section,
  between the cap check and the count, so the two threads really do overlap there.
- E-T6 also covers the self-attack: 10,000 unmatched finishes after a nested `run_scope` error are counted
  (`unmatched == 10_001`) and never raised.

## V2-LOG

- The recorder's open-phase map is not bounded: a producer that starts phases and never finishes them grows it until `close()`. `src/decoy_engine/telemetry/_recorder.py:82` [3]
- A start on a `(phase, table)` key that is already open replaces the earlier start silently, with no counter. `src/decoy_engine/telemetry/_recorder.py:82` [3]
- `start_ns` comes from the wall-clock `PhaseEvent.ts`; the duration comes from the `perf_counter` `elapsed_s`. A wall-clock step between them skews only where the span sits on the timeline. `src/decoy_engine/telemetry/_recorder.py:82`, `:99` [9]
- The E-T5 lock mutation is red only with the test's widened critical section; under the GIL an unlocked recorder does not interleave in practice. `tests/unit/test_telemetry_recorder.py` E-T5 [8]
- Phase events emitted on engine worker threads reach no recorder (thread-local binding; plan V2-LOG). `src/decoy_engine/progress.py:500` [4]
- `run_pipeline(progress=sink)` replaces an outer binding, so the Platform must fan out to its own recorder. `src/decoy_engine/execution/_pipeline.py:276` [4]
